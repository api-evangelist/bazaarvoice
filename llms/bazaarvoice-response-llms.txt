- [Delete Review Response](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/delete-review-response.md): This page describes how to delete a specific client response record.
- [Count Review Responses](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/count-review-responses.md): This page describes how to retrieve a count of responses for a list of reviews.
- [Overview](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/overview.md): This page contains general information about using the Response API.
- [Author](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/author.md): This page describes the response Author resource. The Author resource is the writer of the review response.
- [Review](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/review.md): This page describes the Review resource.
- [Tools](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/tools.md): Listed below is a collection of tools you can use to help you work more effectively with the Response API. These tools are maintained by Bazaarvoice.
- [API Key Management](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/api-key-process.md): This section provides documentation on requesting and managing API keys, and registering the application.
- [Troubleshooting](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/troubleshooting.md): This page has basic steps to help you fix common issues encountered when using the [Response API](/v1.0-ResponseAPI/docs/home). Many issues can be fixed by following the steps below.
- [Security Imperatives](https://developers.bazaarvoice.com/v1.0-ResponseAPI/docs/security-imperatives.md): Security Fundamentals for HTTPS and TLS.
