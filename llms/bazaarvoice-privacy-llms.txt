# Bazaarvoice Developer Space V2.0 Documentation

> Documentation for Bazaarvoice Developer Space V2.0

## Guides
- [Getting Started](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/home.md): The Bazaarvoice Privacy API provides a secure HTTP interface for integrating Bazaarvoice into your General Data Protection Regulation (GDPR), California Consumer Privacy Act (CCPA), and other privacy regulations compliance workflows.
- [Privacy Design Reference](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/privacy-privacy-design-reference.md): Privacy API: Integrate your Bazaarvoice solution into your privacy regulations compliance workflow using a secure HTTP interface
- [API Key Management](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/api-key-management.md): This page explains how to use the API key management application in the Bazaarvoice Portal to view and manage API keys.
- [OAuth2 : 2-Legged](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/oauth2-2-legged.md): The Bazaarvoice Privacy API provides 2-legged and 3-legged methods for **OAuth2** authentication. Use the **[2-legged](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/oauth2-2-legged)** workflow if you want to authenticate your application without a Bazaarvoice Portal user involved in supplying credentials. Use the **[3-legged workflow](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/oauth2-3-legged)** if you want to authenticate your application based on a Bazaarvoice Portal user supplying credentials. Due to its automation advantages, Bazaarvoice expects that the 2-legged workflow best fits the majority of client use cases for the Privacy API.
- [OAuth2 : 3-Legged](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/oauth2-3-legged.md): The Bazaarvoice Privacy API provides 2-legged and 3-legged methods for **OAuth2** authentication. Use the **[2-legged](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/oauth2-2-legged)** workflow if you want to authenticate your application without a Bazaarvoice Portal user involved in supplying credentials. Use the **[3-legged workflow](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/oauth2-3-legged)** if you want to authenticate your application based on a Bazaarvoice Portal user supplying credentials. Due to its automation advantages, Bazaarvoice expects that the 2-legged workflow best fits the majority of client use cases for the Privacy API.
- [Security Imperatives](https://developers.bazaarvoice.com/v1.0-PrivacyAPI/docs/security-imperatives.md): Security Fundamentals for HTTPS and TLS.
